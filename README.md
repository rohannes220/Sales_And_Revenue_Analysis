# Sales and Revenue Analysis

This repository contains my solution for Homework 2. The project focuses on inspecting, tidying, joining, and analyzing sales, shipment, and company revenue data using Python, Pandas, and Matplotlib.

## Repository Structure

- `data/` contains the CSV datasets used in the analysis.
- `src/` contains the Jupyter notebooks for Tasks 0–5.
- `WRITEUP.md` contains the written responses for the assignment.

## How to Download and Run the Project

1. Click the green **Code** button at the top of the GitHub repository.
2. Select **Download ZIP**.
3. Extract the ZIP file on your computer.
4. Open the extracted folder in VS Code or Jupyter Notebook.
5. Make sure Python, Pandas, Matplotlib, and Jupyter are installed.
6. Open the `src/` folder.
7. Run the notebooks in order from `Task 0.ipynb` through `Task 5.ipynb`.

The datasets required for the analysis are included in the `data/` folder.

## Notebook Order

1. `Task 0.ipynb` – Initial data inspection and raw visualization
2. `Task 1.ipynb` – Tidying the revenue dataset
3. `Task 2.ipynb` – Checking key uniqueness and join cardinality
4. `Task 3.ipynb` – Joining orders and shipments and comparing mean order amounts
5. `Task 4.ipynb` – Creating the final analysis-ready table
6. `Task 5.ipynb` – Creating and comparing the final visualization
